# Ambient Mixer — дизайн проекта

Интерактивный генератор атмосферы (Lo-Fi / Ambient Mixer): SPA для микса фоновых звуков с таймерами и динамическим фоном.

## 0. Решения по итогам уточнений

| Вопрос | Решение |
|---|---|
| Цель | Публичный проект для портфолио (деплой, мобильная версия, аккуратный вид) |
| Источник аудио | Файлы в репозитории (`public/audio/`), лицензии CC0 / CC-BY |
| Сохранение состояния | `localStorage` |
| Повторный визит | Громкости помнятся, включённость карточек сбрасывается (старт с тишины) |
| Стиль | Glassmorphism на анимированном градиенте |
| Таймеры | Выкл / Фокус (Помодоро, настраиваемый) / Сон (авто-выключение) |
| Язык интерфейса | RU / EN с переключателем |
| Аудио-подход | Web Audio API (`AudioBufferSourceNode` + `GainNode`) |

## 1. Технологии и структура

**Стек:** Vite + React + TypeScript, Tailwind CSS, Lucide React, Web Audio API. Состояние — `useReducer` + контекст (без Redux/Zustand). Деплой — статический хостинг (Vercel / Netlify / GitHub Pages), бэкенда нет.

**Иконки:** `CloudRain`, `CloudLightning`, `Flame`, `Coffee`, `Trees`, `TrainFront`, Play, Pause и др.

```
public/audio/          # 6 циклических mp3/ogg (CC0 / CC-BY)
src/
  audio/useAudioEngine.ts   # вся работа с Web Audio
  data/sounds.ts            # описание 6 источников (id, иконка, файл, автор)
  state/                    # reducer + сохранение в localStorage
  i18n/                     # словари ru.ts / en.ts, хук useT
  components/
    StartScreen.tsx         # экран «Начать сессию»
    SoundCard.tsx           # карточка: иконка, переключатель, ползунок
    MasterControl.tsx       # мастер плей/пауза + общая громкость
    TimerPanel.tsx          # режимы Выкл / Фокус / Сон
    BackgroundPresets.tsx   # фон и выбор пресета
    LanguageToggle.tsx
  App.tsx
README.md                    # в том числе атрибуция авторов звуков
```

**Принцип:** UI ничего не знает про Web Audio. Он вызывает методы движка (`setVolume(id, v)`, `toggle(id)`, `playAll()`, `pauseAll()`), а движок отдаёт состояние загрузки.

## 2. Аудиодвижок и поток данных

**Граф Web Audio**
```
[Buffer→Source(loop)]→[Gain трека] ─┐
 ... ×6                              ├→ [Master Gain] → destination
                                     ┘
```

**Жизненный цикл**
1. **Стартовый экран.** До клика создаётся только UI. По кнопке «Начать сессию» создаётся `AudioContext` и вызывается `resume()` (обход блокировки автовоспроизведения).
2. **Загрузка.** После старта 6 файлов грузятся параллельно: `fetch` → `decodeAudioData`. Виден прогресс, ошибки показываются на уровне карточки.
3. **Включение/выключение трека.** Источник запускается с `loop = true`; `gain` плавно растёт/падает за 0,5–1 с (`linearRampToValueAtTime`), без щелчков.
4. **Мастер-пауза.** *(уточнено при реализации)* Вместо `audioContext.suspend()` плавно глушится общий «gate»-`GainNode`: контекст продолжает работать, чтобы сигнал таймера прозвучал и при паузе. Состояния карточек не меняются.
5. **Ползунок** меняет `gain.value` через сглаживание (`setTargetAtTime`).

**Состояние (reducer)**
```
tracks: { [id]: { enabled: boolean, volume: 0..1 } }
masterPlaying: boolean
masterVolume: number
bgPreset: 'night' | 'sunset' | 'moss'
lang: 'ru' | 'en'
timer: { mode: 'off' | 'focus' | 'sleep', focus: {...}, sleep: {...} }
```

**Сохранение в `localStorage`:** все поля, кроме текущего хода запущенного таймера. Запись с debounce. При чтении — валидация, невалидное заменяется дефолтами.
**Повторный визит:** восстанавливаются громкости и настройки; `enabled` у всех карточек сбрасывается в `false`.

**Дефолты при первом запуске:** все карточки выключены, громкость каждой 50%, над сеткой подсказка «Включите любой звук, чтобы начать».

**Поток данных:** действие пользователя → `dispatch` → reducer → эффект в `useAudioEngine` применяет изменения к нодам → `localStorage`.

## 3. Таймеры

Над сеткой — панель «Таймер» с тремя режимами. **По умолчанию «Выкл».** Одновременно работает только один режим; переключение сбрасывает текущий таймер.

**1. Выкл.** Микс играет, пока пользователь сам не остановит.

**2. Фокус (Помодоро)**
- Длительности работы, перерыва и длинного перерыва настраиваются вручную (по умолчанию 25 / 5 / 15; длинный перерыв после каждых 4 циклов). Допустимо 1–120 минут.
- Кнопки: Старт/Пауза, Сброс, «Начать перерыв сейчас», «Пропустить фазу».
- Чекбокс «Автоматически переходить к следующей фазе»: если снят, после сигнала таймер ждёт «Продолжить».
- Мягкий звуковой сигнал в конце фазы (*уточнено: синтезируется осцилляторами Web Audio, без отдельного файла*; идёт мимо мастер-цепочки, чтобы пауза его не глушила; разные тона для начала отдыха и работы). Сигнал можно отключить.
- Счётчик завершённых помодоро (например, «3 / 4»).

**3. Сон (таймер выключения)**
- Пресеты: 30 мин, 1 ч, 2 ч, 4 ч и свой вариант (до 12 ч).
- По окончании все звуки плавно затухают (~30 с), затем движок ставится на паузу. Сигнала нет.
- Показывается остаток; кнопки «+15 мин» и «Отмена».

**Общее**
- Отсчёт по целевому времени (`endTime = Date.now() + остаток`), без накопления ошибки в фоновых вкладках.
- Заголовок вкладки показывает остаток, например `🍅 24:13 · Focus`.
- Сохраняются режим и настройки, но не запущенный таймер.
- Таймер Фокуса не включает и не меняет звуки.

## 4. Динамический фон и интерфейс

**Пресеты фона**
- **Night:** глубокий индиго → фиолетовый → тёмно-синий.
- **Sunset:** янтарь → розовый → пурпур.
- **Forest dusk:** глубокий хвойный → приглушённый шалфей → тёмная морская волна.

**Реализация:** слой `fixed inset-0 -z-10` с большим градиентом, анимированным сдвигом `background-position` (период 30–60 с), плюс 2–3 размытых «пятна света». Только CSS, без canvas. Смена пресета — плавный переход (~1,5 с) через CSS-переменные. При `prefers-reduced-motion` анимация отключается.

**Раскладка** (сверху вниз): шапка (название, RU/EN, выбор фона) → мастер-панель (Play/Pause, мастер-громкость) → панель таймера → сетка карточек (3×2 десктоп, 2×3 планшет, 1 колонка телефон).

**Карточка звука:** стеклянная плашка (`bg-white/10 backdrop-blur-xl border-white/20`), иконка, название, переключатель, ползунок. Активная — со свечением и лёгкой анимацией иконки; неактивная приглушена, ползунок заблокирован.

**Стартовый экран:** полноэкранный блюр над фоном, название, подпись, кнопка «Начать сессию / Start session», переключатель языка; плавно исчезает после клика.

**Доступность:** управление с клавиатуры, `aria-label` у ползунков и переключателей, контраст не ниже AA (все темы тёмные, без ярких засветов), видимый focus-ring.

## 5. Ошибки, безопасность, тестирование, деплой

**Обработка ошибок**
- Файл не загрузился/не декодируется: карточка «недоступна» с кнопкой «Повторить», остальные работают.
- `AudioContext` в `suspended`/`interrupted` (например, iOS после звонка): `resume()` при следующем касании и ненавязчивая подсказка.
- Нет Web Audio API: понятное сообщение вместо пустой страницы.
- Повреждённый или недоступный `localStorage`: `try/catch`, валидация схемы, откат на дефолты.
- Error Boundary верхнего уровня с кнопкой «Перезагрузить».

**Безопасность**
- Все аудиофайлы свои (`public/`), внешних запросов во время работы нет.
- Нет бэкенда, аккаунтов и пользовательского ввода в HTML; числовые настройки валидируются и ограничиваются диапазонами; нет `dangerouslySetInnerHTML`.
- Заголовки хостинга: `Content-Security-Policy` (только `self`), `X-Content-Type-Options`, `Referrer-Policy`.
- Минимум зависимостей (React, Lucide, Tailwind), lock-файл, `npm audit`.
- Лицензии: только CC0 или CC-BY. Авторы и ссылки указываются в README и в блоке «Credits» в интерфейсе. Файлы Freesound скачиваются вручную (нужна авторизация).

**Тестирование**
- **Unit (Vitest):** reducer, валидация и загрузка `localStorage`, логика таймеров (fake timers: фазы, длинный перерыв, сон с затуханием, расчёт по `endTime`).
- **Компонентные (Testing Library):** карточка, переключение режимов таймера, переключатель языка.
- **Движок:** `AudioContext` мокается, проверяются вызовы нод.
- **Ручная проверка:** iOS Safari, Android Chrome, десктопный Chrome/Firefox, бесшовность циклов, блокировка экрана и фоновая вкладка.
- Lighthouse: Accessibility и Performance ≥ 90.

**Деплой:** Vercel или Netlify (автодеплой из GitHub). Аудио с долгим кешем (`immutable`), `.mp3` ≈ 128 kbps (или `.ogg` + запасной `.mp3`), общий вес до ~15–20 МБ.
